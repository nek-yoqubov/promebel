# ТЗ: раздел «Обзвон» в CRM — список клиентов для звонков у каждого менеджера

Нек, 24.10.2026.

## Зачем

У каждого менеджера свой список клиентов, которым надо позвонить. Нагрузка у всех примерно одинаковая.
Во время звонка менеджер видит, когда, на какую сумму и что клиент покупал, чтобы называть точные цифры.
После звонка видно, пришёл ли клиент и что купил.

Раздел устроен как «Розыгрыш»: тот же вид списков, та же кнопка «Позвонил», те же роли. Раздел
«Розыгрыш» не трогать.

## Кто участвует

Менеджеры: **Мебельный2, Мебельный3, Мебельный4, Мебельный5, Мебельный6, Мебельный7, Мебельный9,
Мебельный12, Мебельный14** (поле «Должность» сотрудника в CRM). Мебельный8, Мебельный11 и другие
пользователи списков не получают.

## Какие клиенты попадают в список

- Продажи из `public.sales_clean` за период **01.08.2026 – 22.10.2026** включительно.
- Учитываются продажи менеджеров `Мебельный2…Мебельный14`, кроме `Мебельный11`.
- Сумма клиента у менеджера = продажи минус возвраты. Если сумма у всех менеджеров ≤ 0, клиента
  в список не брать.
- Порога по сумме нет: берём всех, даже покупку на 50 сом.

## Распределение (один раз, список фиксируется)

1. **Свои клиенты у Мебельный2, Мебельный5, Мебельный6, Мебельный14** (правка 24.10). Клиент, у которого
   есть покупка у одного из них за период, идёт только этому менеджеру, даже если покупал и у других.
   Других клиентов эти четверо не получают. Если клиент покупал у двоих из четырёх, он идёт тому,
   у кого сумма больше.
2. **Клиенты только Мебельный8.** Клиент, который за период покупал только у Мебельный8, в списки
   не попадает. Сейчас таких 53.
3. **Остальные клиенты** — сейчас их 585 — делятся между пятью: Мебельный3, 4, 7, 9, 12, по 117 на каждого.
   Порядок:
   - норма на менеджера = число клиентов / 5, первые (остаток) менеджеров могут взять на одного больше;
   - пары «клиент — менеджер» сортируются по сумме покупок клиента у этого менеджера, от большей к
     меньшей. Покупки у Мебельный8 тут не учитываются;
   - идём по парам сверху вниз: клиент отдаётся менеджеру, если клиент ещё не распределён и у менеджера
     не набрана норма;
   - кто остался, тот уходит менеджеру, у которого сейчас меньше всего клиентов.

   Ожидаемо: Мебельный2 — 14, Мебельный5 — 78, Мебельный6 — 130, Мебельный14 — 99,
   Мебельный3, 4, 7, 9, 12 — по 117. Всего 906.
4. Распределение записывается в таблицу закреплений со способом «авто». Повторный запуск не должен
   менять уже закреплённых клиентов.
5. Азим и руководство могут вручную перекинуть клиента на другого менеджера, как в «Розыгрыше». Каждое
   перекрепление пишется в историю.

## Список менеджера

Колонки:
- клиент;
- сумма за период;
- число покупок;
- последняя покупка;
- сколько дней не покупал;
- последний звонок и его результат;
- когда перезвонить;
- пришёл ли после звонка.

Сверху — кому ещё не звонили. Внутри — по сумме за период, от большей.

## Карточка клиента (открывается из списка)

**Покупки за период.** Каждый документ: дата, номер, у кого купил (менеджер), сумма документа, возврат
это или продажа. Под документом — товары: название, количество, сумма. Данные из `sales_clean`, как есть.

**Итог за период:** сумма, число покупок, первая и последняя покупка.

**После звонка.** Все покупки клиента с 23.10.2026: дата, сумма, у кого, товары. Это нужно, чтобы видеть,
пришёл ли он.

**История звонков.**

Телефоны клиентов не подтягивать: менеджер набирает сам.

## Звонок

Как в «Розыгрыше»: кнопка «Позвонил», результат (дозвонился / не взял / обещал прийти / отказ),
комментарий, дата «перезвонить» (необязательно). Отмечает только закреплённый менеджер, руководство —
за любого.

## «Пришёл ли»

- **По звонку:** есть ли покупка клиента после времени звонка, у любого менеджера; дата первой такой
  покупки и сумма всех покупок после звонка.
- **По клиенту** в списке: «пришёл» с датой или пусто.

## Аналитика (руководство)

По каждому менеджеру:
- клиентов в списке;
- кому позвонил;
- дозвонился;
- пришли после звонка;
- сумма покупок после звонка.

Отдельно: из всех клиентов в списках сколько пришли среди тех, кому звонили, и среди тех, кому не звонили.

## Данные

- Новые таблицы в схеме `crm` по образцу «Розыгрыша»: закрепления, звонки, история перекреплений
  (RLS и политики как в CRM).
- Суммы и покупки не копировать в CRM: брать из `sales_clean` через функцию в `crm` с проверкой роли.
- Менеджер видит только своих клиентов. Руководство видит всех.

## Как проверю

1. У Мебельный2, 5, 6, 14 только свои клиенты: 14 / 78 / 130 / 99.
2. У Мебельный3, 4, 7, 9, 12 — по 117, в сумме 585.
3. Клиентов, которые покупали только у Мебельный8, нет ни в одном списке.
4. Карточка клиента: покупки за период и суммы совпадают с отчётом 1С по ответственным за 01.08–22.10
   (без отбора по группе «Материалы»).
5. Звонок сохраняется. Покупка клиента после звонка показывается как «пришёл».
6. Менеджер не видит чужих клиентов.
